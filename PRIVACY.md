# Public disclosure boundary

This repository was authored as a clean-room presentation package. It contains explanations and static website assets, not copied tenant exports.

## Safe content

- High-level architecture and platform roles.
- Prose descriptions of flow purpose, inputs, processing stages, outputs and safeguards.
- Fictional, explicitly illustrative examples.
- Qualitative value, scope and stated limitations.
- Presentation HTML, CSS and JavaScript that runs locally without a tenant connection.

## Excluded content

- Tenant, environment, subscription, application, bot, flow and record identifiers.
- Tenant-specific addresses, internal URLs and connection references.
- Tokens, passwords, API keys, authorization headers, cookies or signed links.
- Customer names, contact details, messages, deal values, raw transcripts or actual account histories.
- Original screenshots, private reports, test receipts and local source paths.
- Power Automate definitions/expressions, solution packages, prompt source, agent configurations or backend implementation.

## Website behavior

The showcase uses authored illustrative content. It does not sign in to Microsoft services, execute workflows, query CRM, call an AI model, submit visitor input or embed tenant resources. It does not add analytics. GitHub and GitHub Pages remain third-party hosting services with their own request logging and privacy terms.

## Contributions and disclosures

Do not submit real records, screenshots, exports or credentials to public issues or pull requests. Describe problems generically using fictional examples. If private information is accidentally published, removing a file from the latest commit is insufficient: assess history, caches and forks, and revoke exposed credentials as appropriate.
